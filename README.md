# فهد الشيخي | أعمال وحلول

> نحوّل التعقيد إلى خطوات واضحة، والخطط إلى نتائج.

تطبيق متكامل (واجهة أمامية + خادم خلفي) يفصل بين ثلاثة مسارات:

1. **الموقع الرئيسي** (`#/`) — الهوية الشخصية والمهنية: نبذة، مهارات، خبرات، تواصل. يدعم العربية والإنجليزية مع تبديل فوري للاتجاه (RTL/LTR).
2. **منصة العمل الحر** (`#/freelance`) — «فهد الشيخي للأعمال والحلول»: الخدمات (بوصلة الأعمال، انطلاقة رقمية، مسار النمو...)، الباقات، آلية العمل، معرض الأعمال، ونموذج طلب عرض سعر يُحفظ عبر API.
3. **بوابة العائلة** (`#/family`) — «صلة | بوابة العائلة»: بوابة خاصة بتسجيل دخول (JWT) لإدارة طلبات الخدمة، القضايا والمعاملات، الوكالات والمستندات، المواعيد والجلسات، والتنبيهات (انتهاء الوكالات والمهل)، مع روابط خدمات ناجز.

> صلة = بوابة خاصة لتنظيم ومتابعة معاملات أفراد العائلة، وفق الوكالات والصلاحيات النظامية المعتمدة. لا تُقدَّم عبرها خدمات قانونية للعامة.

## التقنيات

- React 19 + Vite (واجهة أمامية ثنائية اللغة RTL/LTR)
- Node.js + Express (خادم خلفي REST)
- تخزين ملفات JSON تحت `data/` (مستبعدة من Git، وقابلة للاستبدال بقاعدة بيانات منفصلة للبوابة عند الإنتاج)
- مصادقة JWT مع تجزئة كلمات المرور عبر `crypto.scrypt`

## التشغيل

```bash
npm install

# وضع التطوير: خادمان
npm run server   # API على المنفذ 3000
npm run dev      # Vite على 5173 (مع توجيه /api إلى 3000)

# وضع الإنتاج
npm run build
npm start         # يقدم dist/ والـ API من منفذ واحد
```

## متغيرات البيئة

| المتغير | الوصف | الافتراضي |
|---|---|---|
| `PORT` | منفذ الخادم | `3000` |
| `JWT_SECRET` | سر توقيع الجلسات | `change-me-in-production` (غيّره في الإنتاج) |
| `ADMIN_USERNAME` | مستخدم بوابة العائلة الأول | `falshaekhi` |
| `ADMIN_PASSWORD` | كلمة المرور الأولية | `Family@1234` (غيّرها فوراً) |

> تنبيه: في الإنتاج استخدم `JWT_SECRET` قوياً، غيّر كلمة المرور الافتراضية، وفعّل HTTPS ونسخاً احتياطياً يومياً.

## خارطة الطريق

### بوابة العائلة (صلة)
- التحقق بخطوتين (2FA) وسجل عمليات الدخول
- رفع فعلي مشفّر للمستندات وأرشيف عائلي
- لوحة إدارة (إدارة المستخدمين، التحقق من صلة القرابة، توزيع المهام، الصلاحيات، التقارير والإحصائيات)

### منصة العمل الحر
- ✅ لوحة العميل (`#/client`): تسجيل/دخول، طلباتي وحالتها، الفواتير، الدفع (وضع تجريبي)، ورسائل الحالة
- ✅ لوحة الإدارة (`#/admin`): إدارة عروض السعر (6 حالات)، إصدار الفواتير، إشعار العميل التلقائي عند تغيير الحالة أو إصدار فاتورة، وتقارير (عدد الطلبات، الفواتير غير المدفوعة، إجمالي المدفوعات، العملاء)
- ربط بوابة دفع فعلية (مدى/بطاقات عبر مزود سعودي) بدل الوضع التجريبي الحالي
- العقود والتسليمات والرسائل داخل لوحة العميل
- تقارير إدارية موسّعة وتصدير
- الربط مع Microsoft 365 وSharePoint عند الحاجة

### عام
- استبدال تخزين JSON بقاعدة بيانات منفصلة للبوابة
- مدونة المقالات (الإدارة والحوكمة، التقنية، الأعمال والأنظمة)
